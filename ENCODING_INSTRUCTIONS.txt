═══════════════════════════════════════════════════════════════
  📝 TẠI SAO BỊ LỖI?
═══════════════════════════════════════════════════════════════

Vấn đề 1: BOM (Byte Order Mark)
  • Windows text editor thêm BOM vào file UTF-8
  • PHP không đọc được file có BOM
  • Giải pháp: Dùng UTF-8 WITHOUT BOM

Vấn đề 2: ROOT_PATH chưa được define
  • File config.php dùng dirname(__DIR__)
  • Nhưng nếu config không load, ROOT_PATH = undefined
  • Giải pháp: Define ROOT_PATH TRƯỚC khi load config

Vấn đề 3: Encoding không nhất quán
  • Một số file UTF-8, một số ANSI
  • PHP bị confused
  • Giải pháp: Force TẤT CẢ file UTF-8


═══════════════════════════════════════════════════════════════
  🔧 CÁCH SỬA (NẾU VẪN LỖI)
═══════════════════════════════════════════════════════════════

Bước 1: Kiểm tra file encoding

  Cách 1 - Dùng Notepad++:
    1. Mở file: C:\xampp\htdocs\elearning\config\config.php
    2. Menu: Encoding → Encode in UTF-8 (without BOM)
    3. Save

  Cách 2 - Dùng VS Code:
    1. Mở file config.php
    2. Góc dưới phải: Click "UTF-8 with BOM"
    3. Chọn: "Save with Encoding"
    4. Chọn: "UTF-8"
    5. Save


Bước 2: Sửa php.ini

  File: C:\xampp\php\php.ini

  Tìm và sửa:
    default_charset = "UTF-8"

  (Bỏ dấu ; nếu có)


Bước 3: Restart Apache

  1. Mở XAMPP Control Panel
  2. Click "Stop" ở Apache
  3. Đợi 2 giây
  4. Click "Start" ở Apache
