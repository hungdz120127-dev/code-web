## ⚙️ Configuration

### File: config/config.php

**Database:**
```php
DB_HOST: localhost
DB_NAME: elearning_db
DB_USER: root
DB_PASS: (để trống)
```

**URLs:**
```php
BASE_URL: http://localhost/elearning/
```

**Nếu thư mục khác:**
```php
// Thư mục: C:\xampp\htdocs\myproject
define('BASE_URL', 'http://localhost/myproject/');
```

## 🔧 Customization

### Change Colors
File: `public/css/custom.css`
```css
:root {
    --custom-primary: #4361ee;
    --custom-accent: #fbbf24;
}
```

### Change Font
File: `views/layouts/header.php`
Update Google Fonts link

File: `public/css/custom.css`
```css
:root {
    --font-main: 'YourFont', sans-serif;
}
```
